## 应用介绍（可直接粘贴）

阅易是一款本地优先的电子书阅读器，为鸿蒙 PC 而来。

【格式全支持】EPUB / PDF / MOBI / AZW3 / FB2 / CBZ / TXT（含 GBK 编码），竖排、大文件、扫描件 PDF 均可流畅打开。

【阅读体验】深浅色主题随系统、字号字体行距全可调、翻页/滚动双模式、竖排排版，阅读进度与标注自动保存，重启不丢。

【标注与笔记】高亮、下划线、笔记、书签一应俱全，支持精确到段落的定位恢复。

【听书】内置 TTS 语音朗读，调用系统语音引擎，可后台连续朗读。

【开放同步】支持 KOReader 同步协议（自配服务器）、WebDAV 备份，数据自主掌控。

【隐私干净】不采集个人信息，匿名使用统计默认关闭；无广告、无推送、无内置书城。书籍内容全部由您从本地导入，本应用不分发任何内容。

基于开源电子书引擎（AGPL-3.0）移植，源代码公开：https://github.com/serendipityovo/readest

## 审核反馈#1 复现说明（登录-注册无法注册）

登录/注册走上游 readest 官方账号体系（Supabase，*.supabase.co 海外服务），
大陆网络环境不可达导致注册失败——属上游后端依赖，非应用缺陷，客户端无法修复。
已在"测试账号"栏注明"无需登录即可使用全部本地功能"。核心阅读功能 100% 离线可用。
